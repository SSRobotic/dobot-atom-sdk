## 🛠️ What is inside

This repository contains the existing DOBOT Atom SDK source collection, together with its original history and notices. The [original documentation](UPSTREAM_README.md) describes installation, examples and dependencies. Use the documented robot generation and software versions.

## 🚀 Start here

1. Read [UPSTREAM_README.md](UPSTREAM_README.md) and inspect the source tree.
2. Check hardware compatibility, middleware and the dependency versions documented by the original project.
3. Build in the project-specific workspace. This collection has its own setup; the Hub provides navigation and discovery.
